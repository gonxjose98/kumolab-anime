# @animexronin: carousel page analysis (earlier analysis)

- Analyzed: 2026-10-08 (earlier session; summary only, numbers were not saved)
- Page: https://www.instagram.com/animexronin/
- Format: art-first carousels

## What they do

- Two shows per slide. Each slide is split between two titles, so a 10-slide post covers about 20 shows.
- The art fills the frame. Official key visuals or clean screenshots run edge to edge, no frames, no template chrome.
- Text per show is minimal: the show name plus one stat (for example a score, episode count, or ranking). Nothing else on the slide.
- No cover slide. Slide 1 is already content, so the first swipe is value, not a title card.
- Caption is long and keyword-heavy for search: a written intro, then a bracketed keyword list (show names, genres, character names), then 5 hashtags.
- Topics are chosen for saves and shares: lists people bookmark for later or send to a friend ("anime to watch if you liked X" style), not news.

## Why it likely works

- Saves and shares are strong ranking signals for carousels; a dense two-per-slide list is worth saving.
- No cover slide means the preview tile in feed and Explore is already real art, which reads as content, not an ad.
- Keyword-heavy captions get the post into IG search results for show names.

## Takeaways for KumoLab

- Test a carousel with no title slide: open on the strongest art.
- Test two shows per slide with name + one stat, versus one show per slide.
- Add a bracketed keyword list to carousel captions, keep 5 hashtags. Note: this conflicts with the locked "short captions" rule (hook + share CTA + 3 to 5 hashtags), so it needs Jose's OK as a test.
- Pick topics people save ("if you liked X, watch these"), not news.
